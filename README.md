# 📈 CFA Level 1 Master Flashcards App

Welcome to the CFA Level 1 Master Flashcards app! This repository contains a fully functional, mobile-friendly web application designed to help candidates conquer the massive CFA Level 1 curriculum. 

It features **2,000 highly curated flashcards** covering all 10 subjects, built with active recall and procedural drills in mind.

### ✨ App Features
* **📱 Mobile-First Design:** Swipe left and right to navigate cards on your phone.
* **💾 Smart Progress Saving:** The app remembers exactly which card you left off on for every single subject using local browser storage.
* **🎉 Completion Celebrations:** Confetti animations trigger when you successfully finish a deck.
* **📸 Export to Image:** Hit a button to save tricky formulas or concepts directly to your camera roll for easy sharing or offline review.
* **🌙 Dark Mode:** Easy on the eyes for late-night study sessions.
* **🔀 Shuffle Mode:** Randomize the deck to prevent false memory and force true active recall.
